# Get-TdOperationalActivitySettings

## SYNOPSIS
Get settings for operational activities

## SYNTAX

```
Get-TdOperationalActivitySettings [<CommonParameters>]
```

## DESCRIPTION
GET /tas/api/operationalActivities/settings
This endpoint returns whether fields that could be set as mandatory on operational activities are currently mandatory or not

## EXAMPLES

### EXAMPLE 1
```
Get-TdOperationalActivitySettings
```
