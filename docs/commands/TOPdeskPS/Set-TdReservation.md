# Set-TdReservation

## SYNOPSIS
Updates a reservation

## SYNTAX

```
Set-TdReservation [-Id] <string> [[-Occurrences] <string>] [[-BriefDescription] <string>] [[-Notes] <string>] [[-NumberOfPersons] <int>] [[-RequesterId] <string>] [[-OperatorGroupId] <string>] [[-OperatorId] <string>] [[-ProcessingStatusId] <string>] [[-ExternalLinkId] <string>] [[-ExternalLinkType] <string>] [[-ExternalLinkDate] <string>] [[-Body] <hashtable>] [-AllowPassedLeadTimes] [-WhatIf] [-Confirm] [<CommonParameters>]
```

## DESCRIPTION
PATCH /tas/api/reservations/{identifier}
To update status, plannedStart/EndDate, and reservedFacilities, use their respective dedicated endpoints.

Setting the requester will also update all related fields with data from the given person.

Currently, only one external link can be set. Trying to update an existing external link will give an error. Administrators can remove the existing external link.

## EXAMPLES

### EXAMPLE 1
```
Set-TdReservation -Id $id
```

Updates a reservation
