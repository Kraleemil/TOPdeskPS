# Copy-TdAsset

## SYNOPSIS
Copies an asset.

## SYNTAX

```
Copy-TdAsset [-AssetId] <string> [[-NumberOfCopies] <int>] [[-Prefix] <string>] [[-StartAt] <string>] [[-Body] <hashtable>] [-WhatIf] [-Confirm] [<CommonParameters>]
```

## DESCRIPTION
POST /tas/api/assetmgmt/assets/{assetId}/copy
It is only available for active assets. The mandatory fields are dependent on the auto numbering settings of the source asset's template. If it is enabled only the numberOfCopies should be provided. Otherwise prefix and start at are also mandatory.

## EXAMPLES

### EXAMPLE 1
```
Copy-TdAsset -AssetId $assetId
```

Copies an asset.
