# Get-TdChangeSettings

## SYNOPSIS
Returns settings for changes.

## SYNTAX

```
Get-TdChangeSettings [<CommonParameters>]
```

## DESCRIPTION
GET /tas/api/changes/settings
The endpoint returns module settings for change management.

## EXAMPLES

### EXAMPLE 1
```
Get-TdChangeSettings
```

Returns settings for changes.
