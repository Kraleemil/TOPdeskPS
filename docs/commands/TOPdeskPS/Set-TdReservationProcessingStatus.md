# Set-TdReservationProcessingStatus

## SYNOPSIS
Updates a reservation processing status

## SYNTAX

```
Set-TdReservationProcessingStatus [-Id] <string> [[-Name] <string>] [[-Body] <hashtable>] [-WhatIf] [-Confirm] [<CommonParameters>]
```

## DESCRIPTION
PATCH /tas/api/reservationProcessingStatus/{identifier}
Updates the name of a processing status option for reservations and requests

## EXAMPLES

### EXAMPLE 1
```
Set-TdReservationProcessingStatus -Id $id
```

Updates a reservation processing status
